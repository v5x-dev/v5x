---
title: "run"
description: "Build, upload, and immediately start a program."
---

```bash
v5x run [path] [options]
```

Alias: `v5x r`

`run` accepts the same `--slot`, `--name`, `--description`, `--icon`, `--file`, `--no-build`, and `--port` options as `upload`. It always asks the brain to start the uploaded program.

```bash
v5x run --slot 1
v5x run ./robot --slot 4 --name "Autonomous"
```

Add `-t, --terminal` to keep the connection open and stream the program's
output as soon as it starts, so nothing it prints at startup is missed:

```bash
v5x run --terminal
```

See [terminal](/cli/commands/terminal) for the streaming options and how to
send input back to the program.
