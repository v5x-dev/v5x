## Install the standalone CLI

On Linux or macOS, run:

```bash
curl -fsSL https://v5x.dev/install.sh | sh
v5x --version
```

This installs the latest release to `~/.local/bin/v5x`. Set
`V5X_INSTALL_DIR` to use a different directory or `V5X_VERSION` to install a
specific version:

```bash
curl -fsSL https://v5x.dev/install.sh | V5X_INSTALL_DIR=/usr/local/bin V5X_VERSION=0.0.23 sh
```

On Windows, run the PowerShell installer instead:

```powershell
irm https://v5x.dev/install.ps1 | iex
v5x --version
```

This installs the latest release to `%LOCALAPPDATA%\v5x\bin\v5x.exe`. The same
`V5X_INSTALL_DIR` and `V5X_VERSION` environment variables apply:

```powershell
$env:V5X_INSTALL_DIR = "C:\tools\v5x"
irm https://v5x.dev/install.ps1 | iex
```

The standalone CLI does not require Bun.

## Install with Bun instead

```bash
bun add --global @v5x/cli
v5x --version
```

This option requires Bun 1.3.14 or newer on your `PATH`.

The current release supports Linux, macOS, and Windows. On Windows the CLI
talks to COM ports through the Win32 communications API, so it needs no extra
driver or native module beyond the usbser driver Windows already ships. The
`@v5x/serial` browser library is unaffected: it works in any browser that
implements the Web Serial API, regardless of operating system.

## Install a toolchain

<Tabs>
  <Tab title="vexide">
    ```bash
    v5x install vexide
    ```

    This requires Rust and Cargo. It installs `cargo-v5` with Cargo.

  </Tab>
  <Tab title="PROS">
    ```bash
    v5x install pros
    ```

    This prefers pipx. If pipx is unavailable, it falls back to Python pip.

  </Tab>
</Tabs>

VEXcode C++ projects use the compiler and Make environment supplied by their project setup.
